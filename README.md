# Zero-Start Visual Explainer

A Codex skill for explaining unfamiliar concepts, reasoning, research, tools, and workflows from the ground up. It helps produce clear, step-by-step explanations with concrete examples and, when available, a light visual reading interface.

## When to use it

Use this skill when you want to understand a new topic, compare options, follow a worked solution, or make an abstract explanation more concrete. It is intended for substantive teaching, not casual chat or simple fact lookups.

## Example

Ask Codex:

> Use the zero-start-visual-explainer skill to explain how compound interest works from zero, with a worked example.

The skill instructions are in `SKILL.md`; supporting presentation guidance and assets are included in their original directories.
